Aria — Support

Aria is a music player for your own files and your own music server.

Getting started

How do I add music?

Library tab → Import. Pick files from the Files app — FLAC, ALAC, AIFF, WAV, MP3 and AAC all work. Aria Pro also imports whole folders and M3U playlists.

How do I connect my server?

More → Backend. Choose Subsonic for Navidrome, Airsonic, Gonic, Astiga or any Subsonic-compatible server, enter its address (the server root, not /rest), your username and password, then tap Test Connection. The Search tab appears once a server is configured.

Test Connection fails with "Wrong username or password"

The server rejected the login. Check the username and password in your server's own web interface first. Some servers require a Subsonic-specific password — Navidrome uses your normal one.

Test Connection says the response wasn't valid Subsonic JSON

The URL is probably pointing at a web page rather than the server root. Use just the scheme and host, e.g. https://music.example.com, without /rest or /app.

My server is plain http:// and Aria can't reach it

iOS blocks unencrypted connections except to local-network addresses. Servers on .local names or local hostnames work; a server reached over the internet needs HTTPS. Putting it behind a reverse proxy with a certificate, or a tunnel, is the usual fix.

Sound

How do I use AutoEQ?

Player → EQ → AutoEQ Profile. Search for your headphones and apply the measured correction. Save it as a profile to switch between headphones later. Requires Aria Pro.

Does Aria do bit-perfect output to a USB DAC?

No. iOS mixes all audio through a fixed-rate system mixer; Aria matches the mixer to 44.1 or 48 kHz families but cannot bypass it. This is a platform limit, not an Aria setting.

Purchases

I bought Aria Pro on another device

More → Aria Pro → Restore Purchases. Purchases are tied to your Apple ID.
